#### 🛒 Fullkala — Multi-tenant E-commerce Platform
> A production multi-tenant e-commerce platform built entirely solo with Next.js and NestJS.
- **Architecture:** Turborepo monorepo across 4 projects (storefront, admin, landing, API)
- **Stack:** Next.js 16, React 19, NestJS, Prisma, PostgreSQL, Spree Commerce
- **Highlights:** Strict tenant isolation, full payment/order/inventory management, 40% faster page loads via Core Web Vitals optimization.
- 🔗 [fullkala.com](https://fullkala.com)

#### 🤖 AI Job Finder — Python Automation
> An AI-powered job discovery and application assistant built in Python.
- **What it does:** Scrapes job boards, scores fit against a CV, generates tailored PDFs and cover letters, and assists with form filling using a human-in-the-loop apply flow.
- **AI Layer:** Custom API layer over free LLM services — turning chat interfaces into programmable, reliable services at near-zero marginal cost.
- **Stack:** Python, FastAPI, Playwright, CustomTkinter, Pydantic, ReportLab, BeautifulSoup, httpx, pytest
